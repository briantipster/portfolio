# Brian's Developer Portfolio

A responsive personal portfolio website with a dark navy theme and electric-blue accents.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling
- `script.js` — mobile navigation, current year, and copy-profile interaction

## Preview locally
1. Extract the ZIP.
2. Open the `brian-developer-portfolio` folder in VS Code.
3. Install the **Live Server** extension if needed.
4. Right-click `index.html` and select **Open with Live Server**.

You can also double-click `index.html` to open it directly in a browser.

## Publish with GitHub Pages
1. Create a new GitHub repository named `brian-developer-portfolio`.
2. Copy these files into that repository folder.
3. Open a terminal in that folder and run:

```bash
git init
git add .
git commit -m "Create developer portfolio"
git branch -M main
git remote add origin https://github.com/briantipster/brian-developer-portfolio.git
git push -u origin main
```

4. On GitHub, open the repository's **Settings → Pages**.
5. Under the build/deployment section, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

Your portfolio should become available at `https://briantipster.github.io/brian-developer-portfolio/` after GitHub Pages finishes publishing.

## Personalize before publishing
Review the project descriptions and skill levels so they accurately reflect your current progress. Add your preferred contact method when you are ready.
